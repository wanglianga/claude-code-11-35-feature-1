# 收运批次重量一致性、计费差异与时空证据数据服务

面向数据团队与财务分析的可审计数据服务：对同一收运批次，环卫（门岗/任务）、地磅与处理场常给出不同的重量、时间与费用依据。本服务将三方证据汇总为**可审计的收运重量、计费依据与差异范围**，让财务知道哪些金额可确认、哪些仍需复核。同时提供**时空证据状态**能力：车辆轨迹穿过多边形不等于收运可信，定位漂移、退役终端上报与长时间补传都可能画出看似完整的路线，系统对每条批次输出可信/受限/不可认证/待核四态，并支持定位、终端安装期、精度、走廊、门岗、地磅、签收锚点下钻。

**服务边界**：本服务不派车、不预约卸料、不审批付款，只发布可审计的数据产品；时空证据只描述证据支持度，不补画缺失路段、不把缓冲区停留认作门岗通过。

## 领域组件

| 组件 | 职责 |
| --- | --- |
| 来源证据库 | 保存收运任务、门岗记录、地磅读数、处理场签收、费率目录、账务回执的**原文、事件时间、设备/场地标识、校准版本与内容哈希**（SHA-256，事件时间归一化 UTC 后计算，入库前后可重算核对） |
| 批次关系册 | 维护任务、车辆、称重、签收间的**候选/确认**关联；同一称重被两个批次候选引用时**冻结分配**，直到证据确定 |
| 计量裁定器 | 按合同策略签发**合同计费重量**（优先级裁定）或**可接受区间**（区间裁定），并记录待核冲突与排除原因；任何来源都不会被直接当作无条件真值 |
| 费率编译器 | 仅在**冻结目录**上生成金额事实；目录在服务后修订时生成**新解释版本**（仍引用服务当时有效目录），不回写历史 |
| 差异发布器 | 输出**计费依据、未决范围与下游引用版本**（`PUB-{批次}-v{N}`）；发布记录不可变 |

### 两种裁定策略（按合同类型选择，报表中明确标注）

- **优先级裁定**：签收、地磅、门岗满足合同约定的时间/校准条件时，依序选定一份计费重量，其余合格来源作为差异佐证。结算及时、规则稳定；主来源缺失或校准争议时留下待核金额。
- **区间裁定**：对满足质量门槛的多份重量签发可接受区间，仅在**区间重叠**或存在**已批准的换算依据**时形成计费事实；上下界分别编译边界金额，**跨越费用阶梯时分别列示、不取中点伪造已确认金额**。月结报表中相应显示更多未决范围。

### 关键规则

- **签收后离场**：不能仅以最后定位晚于签收认定矛盾——必须比较支持到场的定位片段、设备时钟校正与容差（`departure` 服务）。
- **校准更正**：受影响计量事实转为**复审中**，新计费视图暂停引用（发布为 `paused`），旧账务视图保留原依据；重新裁定时自动适用更正系数并留痕。
- **费率修订**：以**服务时间当时有效**的冻结目录生成新解释版本，历史金额事实标记 `superseded` 但内容不回写。

## 时空证据状态（四态 + 双引擎）

轨迹穿过多边形只是几何事实，不是收运可信的充分条件。系统用两套互补机制评估，并把结论与理由都留痕：

### 声明式证据规则（逐项检查、理由透明）

阈值集中声明（采样空洞 120s、速度上限 90km/h、低精度 30m、补传滞后 30min、锚点互证窗 15min），每条规则输出 通过/受限/待核/不通过 与阻断标记：

| 规则 | 检查内容 | 关键纪律 |
| --- | --- | --- |
| R1 终端有效性与归属 | 安装期、退役状态、同车双终端重叠 | 退役终端与无安装记录终端的定位不可采信；旧终端与新终端同时有效时标**归属冲突**，任一方不得单方面采信 |
| R2 采样空洞 | 相邻定位间隔超阈值 | 只陈述空洞，**绝不补画**缺失路段，空洞内位置保持未知 |
| R3 速度连续性 | 相邻点位移/时间 | 通信中断/长时间补传后的**跳速保持未知**，不推断超速也不推断矛盾；精度圆内位移同样记未知 |
| R4 目标区域交集 | 精度感知的点面关系 | 精度圆覆盖多边形边缘时只判**边缘待核**，低精度不能断言入域 |
| R5 门岗与缓冲区 | gate 区域命中 | **缓冲区停留不构成门岗通过**，两者分别列示 |
| R6 道路走廊归属 | 轨迹与走廊交集 | 同时落在两条走廊时标**双走廊**，入域路径归属待核 |
| R7 补传与载荷完整性 | 补传滞后、同序列哈希 | 同序列号不同哈希的两份载荷**都保留**并登记冲突，判不可认证；相同哈希重传幂等 |
| R8 锚点时序与离场 | 门岗→地磅→签收时序与互证 | 收运任务是计划单据不参与时序冲突；**签收后的正常离场不算时序冲突** |

四态聚合：任一阻断性规则不通过 → **不可认证 uncertifiable**；其次存在待核/不通过 → **待核 review**；仅存在受限警告 → **受限 limited**；全部通过 → **可信 trusted**。锚点单据不能把低精度轨迹"洗成"可信，状态不被业务单据覆盖。

### 状态空间路径推断（稀疏点下更有用，依赖道路模型与校准）

把道路模型（版本化、标注是否校准）、定位精度、时间连续性与锚点合并为 HMM 式状态空间：高斯发射似然（σ 取精度半径）+ 沿真实道路边的 Dijkstra 转移 + Viterbi 保留 **top-6 候选路径**并 softmax 归一化：

- 入域判定只采信**观测吸附节点**并带入观测自身精度——低精度观测最多产生"边缘待核"概率，道路插值节点不补画入域事实；
- 道路模型缺边或转移超速时登记为候选空洞（`gaps`），**不虚构边、不补画路段**；节点回绕显式降权并计数；
- 道路模型未校准时声明"概率仅为相对似然，非绝对置信度"；同序列载荷冲突时推断仍保留双分支，但整体标注不可认证。

### 下钻维度

批次时空证据页一站回查：**定位点**（校正时间/精度/补传/有效性/载荷哈希）、**终端安装期**（安装/退役时间）、**精度**（低精度红色标注）、**走廊**（双走廊候选）、**门岗/地磅/签收锚点**（定位互证点与边缘待核点）、规则明细与候选路径。

## 快速开始

### 方式一：Docker Compose（一键）

```bash
docker compose up --build
```

- 前端：http://localhost:8080 （nginx 反向代理 `/api` 到后端）
- 后端 API：http://localhost:8080/api （直连可用 http://localhost:8000/api ，容器内自动建表并写入演示数据）

### 方式二：本地开发

前置：PostgreSQL 运行于 127.0.0.1:5432（库/用户/密码均为 `ccdev`，可用 `DATABASE_URL` 覆盖）。

```bash
# 后端（终端 1）
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python seed.py                 # 建表 + 写入演示数据（幂等，可重复执行）
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000

# 前端（终端 2，开发模式，/api 代理到 8000）
cd frontend
npm install
npm run dev                              # http://localhost:5173
```

```bash
cd frontend && npm run build && cd ../backend
```

## API 概览

全部业务接口位于 `/api` 下，除登录外均需 `Authorization: Bearer <token>`：

- `POST /api/auth/login` · `GET /api/auth/me` · `POST /api/auth/logout`
- `GET/POST /api/evidence` · `GET /api/evidence/{id}` — 来源证据库（写入即算哈希）
- `GET/POST /api/batches` · `GET /api/batches/{id}` — 批次全量审计视图（证据链+裁定+金额+发布+核查）
- `POST /api/batches/{id}/links` · `POST /api/links/{id}/confirm|reject` — 批次关系册（争用自动冻结）
- `POST /api/batches/{id}/adjudicate` — 计量裁定（按合同策略）
- `POST /api/batches/{id}/compile` — 费率编译（冻结目录，新解释版本）
- `POST /api/batches/{id}/publish` — 差异发布（复审中自动 `paused`）
- `POST /api/batches/{id}/departure-check` — 签收后离场核查（定位片段+时钟校正+容差）
- `GET /api/contracts` · `GET/POST /api/rate-catalogs` — 合同与冻结费率目录
